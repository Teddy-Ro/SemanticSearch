# Семантический поиск

Семантический поиск сопоставляет смысл запроса и документов. Эмбеддер преобразует текст в числовой вектор, а база данных находит близкие векторы.

## Разбиение на чанки

Длинный документ делится на фрагменты. Каждый фрагмент сохраняет название документа, заголовки раздела и координаты исходного текста.

## Источники

Для каждой папки можно выбрать свой способ разбиения. Поиск можно ограничить определённой директорией и всеми её вложенными папками.
